# Pendo & Rya – Playland Run V3

Bu paket tek dosyalık prototipten ayrılmış ilk gerçek proje sürümüdür.

Dosyalar:
- index.html — arayüz
- styles.css — görsel tasarım
- main.js — Three.js oyun motoru
- cover.png — onaylanan görsel stile yakın açılış görseli

Sonraki adım:
- Pendo.glb ve Rya.glb gerçek 3D modelleri
- koşma / zıplama / kayma animasyonları
- mıknatıs / kalkan / 2x / hoverboard
- Playland iç mekanının daha detaylı 3D modeli

GitHub repo köküne bu 4 dosyayı yükleyin. Vercel otomatik deploy edecektir.
